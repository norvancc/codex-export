OpenAI Codex CLI session exporter

codex-export

Export OpenAI Codex CLI sessions into readable Markdown, HTML, and JSON for AI coding worklogs, team documentation, retrospectives, and long-term archives.

中文简介：将 Codex CLI 会话记录导出为 Markdown、HTML、JSON，方便做开发日志、复盘文档和 AI 协作归档。

View on GitHub Read the README

Why people use it

  • Convert Codex session history into Markdown worklogs
  • Share HTML exports with teammates or stakeholders
  • Keep JSON archives for automation and reporting pipelines
  • Generate daily, weekly, and timeline reports from local Codex usage

Key features

  • Interactive session picker with fuzzy search and latest-first sorting
  • CLI mode for scripts, batch export, and CI workflows
  • Clean, full, tool-call, and tool-result export scopes
  • Secret redaction for common API keys, tokens, and credentials

Quick start

npm install
npm run build
npm link

codex-export --last --format md --output exports/codex-session.md
